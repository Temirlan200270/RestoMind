# docs/sprints — временные документы по спринтам

Папка для **временных** документов на 1–2 недели: мини‑родмапы, чеклисты, заметки по фиче, короткие решения.

## Правила

1. **Source of Truth по задачам — только `docs/ROADMAP.md`.**  
   В спринт‑доках можно держать *временную* группировку/план, но статус задачи отмечаем **только** в `docs/ROADMAP.md`.

2. **Короткий срок жизни.**  
   После спринта: либо удаляем файл, либо “вплавляем” полезное в `docs/CONVENTIONS.md` / `docs/UI_DESIGN_SYSTEM.md` / `README.md` / `codebase.md`.

3. **Один спринт = одна папка.**

## Шаблон структуры

Создаём папку `docs/sprints/YYYY-MM-DD__<slug>/` и кладём внутрь:

- `README.md` — цель спринта, 3–7 пунктов, риски, “definition of done”
- `NOTES.md` — короткие заметки/наблюдения

Шаблон для старта: `docs/sprints/_TEMPLATE/README.md`.
