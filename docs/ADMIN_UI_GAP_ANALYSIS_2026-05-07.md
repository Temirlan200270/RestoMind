# Анализ админ‑панели RestoMind по списку улучшений (2026‑05‑07)

Цель: зафиксировать, **что уже реализовано в текущем репозитории**, что сделано частично, и что отсутствует по пунктам 1–21.

---

## TL;DR (итог)

- **Сильнее всего закрыто**: статусы доставки WhatsApp‑сообщений в админке (включая “failed” и “resend”), базовая аутентификация/выход, база знаний (CRUD + подстановка в промпт), упаковка (правила в БД + расчёт + CRUD), фундамент мультитенантности (`organization_id`, выбор филиала).
- **Главный UX/Perf‑долг**: один большой `admin.html` (Alpine инициализирует скрытые вкладки → тяжёлый DOM и падение Performance по Lighthouse).
- **Крупные отсутствующие блоки**: полноценный Telegram‑бот “для операторов”, push‑уведомления, рассылки/лояльность, BI‑аналитика продаж iiko по времени суток, “экстренное закрытие” и workflow “вне рабочего времени”.
