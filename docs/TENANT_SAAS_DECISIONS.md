## 4. Согласованность с кодом

- В БД уже есть `tenants`, `organizations.tenant_id`, шифрование iiko по франшизе.
- Superadmin создаёт организацию с привязкой к tenant — без изменений до появления ролей из §1.

После утверждения таблиц выше — задачи на реализацию: проверки в `admin_org_from_session`, список org для владельца сети, UI переключателя, поля брендинга, затем подпроект биллинга.
