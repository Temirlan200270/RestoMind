# Admin UI Baseline Screenshots

This directory is the local output target for admin visual-regression screenshots.

PNG files are generated by:

```bash
python scripts/capture_admin_u0_baseline.py
```

The generated PNG artifacts are intentionally ignored by git. Regenerate them during a UI review or before a manual visual smoke pass, then compare locally.

Tracked source of truth:

- UI map: [../UI_MAP.md](../UI_MAP.md)
- Design system: [../UI_DESIGN_SYSTEM.md](../UI_DESIGN_SYSTEM.md)
- Capture script: [../../scripts/capture_admin_u0_baseline.py](../../scripts/capture_admin_u0_baseline.py)
