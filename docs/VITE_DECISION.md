# Техрешение: Vite для админки RestoMind

**Статус (2026-04): не внедряем Vite**, пока фронт админки остаётся шаблонами Jinja2 + Alpine.js + одним `admin-app.js`.

## Обоснование
- Текущий стек закрывает задачи без сборочного конвейера: быстрый деплой, мало точек отказа, нет рассинхрона версий бандла и серверных шаблонов.
- Переход на Vite имеет смысл при **росте сложности** (дизайн-система на десятках компонентов, SSR не нужен, но нужны code-splitting, TypeScript на всём UI, локальные пакеты). Порог: появление отдельного SPA-маршрута или >3 изолированных JS-приложений внутри админки.

## Если решение пересмотреть
1. Вынести `admin-app.js` в TypeScript-пакет с Vite library / app mode.
2. Сохранить Jinja только как shell (`base.html`) + JSON bootstrap для Alpine или миграция на чистый Vue/Svelte.
3. CI: `npm ci` → `vite build` → публикация `static/dist` + cache-bust.
