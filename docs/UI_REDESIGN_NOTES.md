# UI Redesign — заметки по baseline (Phase U0)

Документ дополняется по мере прохода фаз U1+. Ниже — визуальный долг по снимкам из [`docs/ui/baseline/`](ui/baseline/) (демо-сессия, десктоп 1440×900).

## Общие наблюдения

- Палитра и плотность: смесь `brand-*`, `slate-*`, `emerald-*`, `violet-*` в одном экране без единой шкалы токенов — для U1 завести `--color-*` и семантические роли.
- Сайдбар и шапка: сильный контраст тёмный/светлый работает, но типографика меток секций (`ОБЗОР`) очень мелкая — риск читаемости (WCAG).
- Модалки и `z-index`: в baseline не разворачивались; на редизайне проверить единый стек (см. правила в `.cursor/rules/ui-redesign.mdc`).

## По разделам

### Дашборд (`admin_dashboard.png`)

- Много KPI-блоков в одном вертикальном потоке без явной визуальной иерархии «главное / второстепенное».
- Бейджи демо и готовности конкурируют за внимание с основным заголовком.
- **Оставить на U1+:** вынос карточек в макрос `_kpi_card` / `_card`, полоска AI Value (Phase U2).

### Настройки — подвкладки (`admin_settings_*.png`)

- Дублирование навигации: чипы сверху + десктопная колонка слева (для части вкладок) — согласовать в одном паттерне (`_tabs`).
- «Мой ресторан» / упаковка / график: длинная простыня, много inline-полей — группировать в секции с `_section_header`.
- «Тест бота» и «Технический доступ» относительно компактны — хорошие кандидаты для первых миграций на компоненты.
- **Оставить на U1+:** брендинг (превью после E2.2.B), iiko-онбординг без ломки контрактов.

### Ошибки, Требует внимания, Помощь клиентам (`admin_errors.png`, `admin_incidents.png`, `admin_operator_queue.png`)

- Таблицы и списки визуально разные; статусы и бейджи стоит унифицировать через `_status_badge` / `_badge`.
- Пустые состояния не везде одинаковы — `_empty_state` в U1.

### Бронирования, Диалоги (`admin_bookings.png`, `admin_chats.png`)

- Чаты: двухколоночный layout плотный; на мобильном (отдельный baseline позже) проверить drawer вместо модалок.
- **Оставить:** логику выбора телефона и hash `#chats?phone=…` без изменений.

### Меню, Стоп-лист (`admin_menu.png`, `admin_stoplist.png`)

- Таблицы с разной шириной колонок и фильтрами — кандидат на `_table` с фиксированными правилами плотности.
- Стоп-лист: акцент на статусе синхронизации — хорошо; вынести цвета в токены.

### Заказы (`admin_orders.png`)

- Канбан/списки — самый нагруженный экран; редизайн только после `_card` для карточек заказа и единой модалки (план U4+).

### Аналитика, Вклад ИИ (`admin_analytics.png`, `admin_ai_value.png`)

- Графики Chart.js встроены в карточки с разными отступами — выровнять сетку и заголовки периодов (`_segmented`, `_kpi_card`).
- Вклад ИИ: связка с дашбордом по смыслу — позже сквозной AI Value (Phase U2).
