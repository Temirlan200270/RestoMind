# Phase 13.1 — WhatsApp: шаблоны Meta, голос, «графический чек»

Интерактивные сообщения и проактивные шаблоны в WhatsApp возможны только через **одобренные в Meta** шаблоны (Business Manager → WhatsApp → Message templates).

## 1. Переменные окружения (имена шаблонов)

Задаются на сервере; при пустом значении код **не вызывает** `send_template` для соответствующего сценария.

| Переменная | Назначение |
|------------|------------|
| `WHATSAPP_TEMPLATE_ORDER_RECEIPT` | Шаблон «чек» / итог заказа (тело с подстановками `{{1}}`, …). |
| `WHATSAPP_TEMPLATE_ORDER_STATUS_BUTTONS` | Шаблон со статусом и кнопками (Quick Reply / URL — как одобрено в Meta). |
| `WHATSAPP_TEMPLATE_LANGUAGE` | Код языка шаблона (по умолчанию `ru` — должен совпадать с одобренным в кабинете). |

В коде: `app/integrations/whatsapp.py` — функции `phase13_order_receipt_template_name()`, `send_phase13_order_receipt_template()`, `phase13_order_status_template_name()`.

## 2. Имена шаблонов в Business Manager

**Заполните фактические имена после approve:**

| Сценарий | Имя шаблона в Meta | Язык | Примечание |
|----------|-------------------|------|------------|
| Чек / подтверждение заказа | _указать_ | ru | Параметры: сумма, номер заказа, ссылка Kaspi — по полям шаблона. |
| Статус + кнопки | _указать_ | ru | Кнопки только если включены в шаблоне. |

## 3. Формат «чека»

Варианты (выбрать продуктом):

1. **Текст в template** — параметры body из заказа (проще всего для Meta review).
2. **Изображение** — загрузка media через Graph API, затем сообщение типа `image` (нужен asset в админке или генерация PNG/PDF на сервере).
3. **PDF** — обычно как документ по ссылке (не inline в WhatsApp без одобренного flow).

Рекомендация для первого релиза: **template + текстовые подстановки**; графику добавить позже, когда будет утверждён макет и политика Meta для категории шаблона.

## 4. Голос

Голосовые ответы гостю при включённом `WHATSAPP_VOICE_REPLIES` обрабатываются отдельно от шаблонов; шаблоны нужны для **проактивных** исходящих вне 24-часового окна или для структурированных карточек.

## 5. Интеграция в приложении

Следующий шаг после approve шаблонов: вызов `send_phase13_order_receipt_template` из workflow подтверждения заказа / вебхука (см. `app/api/webhooks.py`, сценарии после оплаты). Обработка нажатий кнопок — расширение вебхука входящих сообщений (тип `button` / interactive).
